# Privacy policy

Last updated: 2026-10-16

This policy applies to the OAuth client "Mac Backup rclone".

1. The client is used only by its owner, to back up the owner's own Mac to the owner's own Google Drive.
2. The client asks only for the `drive.file` scope. With this scope, it can see only the files that it created itself.
3. restic encrypts all backup data on the Mac before upload. The client does not send the data to any party other than Google Drive.
4. No data is sold, shared, or used for advertising.
5. The owner can remove the access at any time from the Google Account permissions page.
